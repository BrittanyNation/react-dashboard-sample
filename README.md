# React Dashboard Sample — PulseBoard

A small React dashboard: stat cards, a filterable data table, and bar visualizations built from data — no chart library. Data comes from a local mock module (`src/data.js`) that mimics an API layer, so swapping in a real endpoint later touches one file.

## Skills demonstrated
- React components, props, and state (hooks)
- Derived data and filtering in the UI
- A clean data-layer boundary (mock API module)
- Responsive layout with plain CSS

## Run it
```bash
npm install
npm run dev
```
